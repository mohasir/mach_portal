Event types are created and edited from `Event Types`. The form asks for a Name (required, can't
be repeated) and a **Color**.

![Color picker](/support/crear-tipo-de-evento-y-color/1.png)

## The color

You can pick one of **15 preset colors** or enter a custom color in hex format (`#RRGGBB`, no
transparency) from the same color wheel. If you don't pick one, the event type is left with the
default blue (`#1677ff`).

That color is used **only in the Events calendar** — every event with that type is painted with an
accent bar and a background tint in that color. It's not shown on the event's page, the quotes
pipeline, or the PDF.

![An event type's color on a calendar card](/support/crear-tipo-de-evento-y-color/2.png)

## A current limitation

Right now **there's no way to deactivate an event type from the interface** — the only available
actions are Edit and copying the ID. An event type you no longer use keeps showing up as an option
forever; the only thing you can do is rename it or change its color.
