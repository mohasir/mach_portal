`Settings → General` (Admin role) has two cards related to quotes.

## Quote defaults

Default deposit (%), Quote validity (months — the expiration date depends on this), Minimum
people per line, Quote sequence start, Currency and Options selection deadline (days before the
event).

> The sequence start **can't be lowered** below the last number already used — the system rejects
> it if you try.

![Quote defaults card](/support/impuestos-y-valores-por-defecto/1.png)

## Taxes by State

An "Apply tax by State" switch + a rate (%) for each of the 3 supported States (NY/NJ/CT). If the
switch is on, at least one rate has to be greater than 0.

![Taxes by State card](/support/impuestos-y-valores-por-defecto/2.png)

## Important: this doesn't touch existing quotes

Changing any of these values **only affects quotes created afterward**. Existing ones keep the tax
rate and values they had when they were created — they don't recalculate on their own.
