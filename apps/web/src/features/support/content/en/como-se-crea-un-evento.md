There's no "New event" button anywhere in the app — events are always born the same way.

## The only path: confirming a quote

When you move a quote to the **Confirmed** stage, the system creates the event automatically, in
the same operation. If you need to schedule something, the path is always: build a quote → send
it → confirm it.

![Confirming a quote](/support/como-se-crea-un-evento/1.png)

## What the event inherits from the quote

When it's created, the event copies: client, event type, date, time, State, city, address and the
quote's **total amount** (as a snapshot of that moment).

What's **not** copied separately are the stations and their options — the event simply reads the
lines and selections from the original quote through the link between them.

## What can't be edited from the event

Client, date/time, address, event type and total amount **can't be edited from the event's page**
— they live in the quote, and can only be changed if that quote is still in an editable stage
(Pending or Sent). Once the quote is Confirmed, those fields are locked.

After confirming a quote, the app takes you straight to the newly created event's page so you can
assign staff.
