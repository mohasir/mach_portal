Your team has 3 possible roles. This is the central reference — the rest of this Help Center's
articles mention it instead of repeating it.

## The 3 roles, in one sentence

- **Admin**: runs day-to-day business almost entirely (quotes, events, payments, clients, staff,
  catalog).
- **Manager**: **read-only** access to almost everything (sees the pipeline, events, clients,
  catalog) plus the full Dashboard — can't create, edit or change anything.
- **Member**: no access to anything protected by the permission system. It's the role any new
  account gets until it's assigned a different one.

Some things (user account management, certain system settings) aren't handled by any role on
your team — they're managed by Mach Bar's support team. Articles that mention them call this out
specifically.

## Table by area

| Area | Admin | Manager | Member |
|---|---|---|---|
| Quotes and Pipeline | Full | Read-only | No access |
| Events | Full | Read-only | No access |
| Payments | Full | **No access** (doesn't even see the tabs) | No access |
| Clients | Full | Read-only | No access |
| Staff | Full | Read-only | No access |
| Catalog | Edit and deactivate (reactivating goes through support) | Read-only | No access |
| Event types | Full | Read-only | No access |
| Dashboard | Full | Full | No access |
| Taxes, defaults and PDF template | Full | No access | No access |
| Quote stages and system preferences | Managed by support | No access | No access |
| User accounts (create, edit, remove) | Managed by support | No access | No access |
| Profile, Security and About | Yes | Yes | Yes |

## How to read this in practice

- If someone's missing a button or an entire tab that you can see, it's probably role-based — not
  necessarily a system bug.
- Anything marked "managed by support" doesn't depend on your role: nobody on your team has it
  available, you need to ask Mach Bar's support team for it.
