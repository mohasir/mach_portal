There are two ways to add a new client, with different levels of detail.

## Full form

From `Clients → New client`: Name (required), Email, Phone, State, City, Address and internal
Notes (up to 2000 characters, the client never sees them).

![Full new-client form](/support/cargar-un-cliente/1.png)

## Quick add from the quote builder

While searching for a client in the builder, if you don't find them, an "Add new client" option
shows up — a mini-form with only **Name** (required), **Phone** and **Email**, no city, state,
address or notes.

![Quick client add from the builder](/support/cargar-un-cliente/2.png)

This client **isn't saved at that point**: their data stays in the quote's draft and only gets
created in the database once the quote is saved. If the builder is left without saving, that
client never actually gets created and would need to be added again.

If you later need to fill in State/City/Address for a client added this way, go to their page and
edit it from there.
