The calendar (`Calendar` in the menu) has two available views: **Month** and **Week**.

![Calendar in month view](/support/ver-eventos-en-el-calendario/1.png)

## Month view

A monthly grid. On small screens, each day only shows color dots (one per distinct event type that
day). On desktop/tablet, each day shows up to 3 event cards (client, event type and time) and a
"+N more" if there are more.

## Week view

- On mobile: a vertical list, one block per day with its events.
- On desktop: an agenda-style grid with time slots. Events without a time set are grouped
  separately, at the top, in an "all day" row.

![Calendar in week view](/support/ver-eventos-en-el-calendario/2.png)

## Colors by event type

Each event is painted with its event type's color (an accent bar + a soft background tint) — so
you can quickly tell what kind of events you have on a given day. It's configured from Event
Types (see
[How to create an event type and pick its color](/admin/settings/support/crear-tipo-de-evento-y-color)).

> This color is **only visible on the calendar**. On the event's page, the event type shows up
> without any color.

## Creating a quote from a date

If you have permission to create quotes, clicking an empty day (month view) or a day's number
(week view) takes you straight to a new quote's builder, **with that date already filled in**. It
doesn't work on past dates.

Clicking an existing event (the card with the client's name) always takes you to that event's
page.
