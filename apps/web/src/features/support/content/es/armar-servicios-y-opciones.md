Dentro de cada estación hay dos niveles más: **secciones** (o servicios) y **ítems** dentro de
cada sección.

![Servicios de una estación](/support/armar-servicios-y-opciones/1.png)

## Crear una sección

Desde el detalle de la estación, pestaña "Servicios", botón "Nueva sección". Pide:

- **Nombre** (obligatorio).
- **Tipo**: **Seleccionable** (el cliente elige cuáles quiere) o **Incluido** (vienen todos
  siempre, es informativo, el cliente no elige).
- Si es Seleccionable: **Selección máxima** (opcional — vacío significa sin límite de cuántos se
  pueden elegir).

## Agregar ítems

Dentro de una sección ya creada (expandiéndola), botón "+". Cada ítem tiene Nombre (obligatorio)
y Descripción (opcional, pensada para detalle de ingredientes).

![Agregar un ítem dentro de una sección](/support/armar-servicios-y-opciones/2.png)

## Cómo se ve esto al cotizar

- Las secciones **Incluido** aparecen ya marcadas, sin poder tocarlas.
- Las **Seleccionables** dejan elegir hasta el máximo definido (o sin límite si no se definió
  ninguno).

Si una sección cambia de Incluido a Seleccionable (o al revés) después de que ya existan
cotizaciones con esa estación, esas cotizaciones **no se actualizan solas** — conservan lo que
tenían al momento de cotizarse.
